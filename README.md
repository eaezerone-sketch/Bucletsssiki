# Орбита

Космическая аркада в один тап. Спутник крутится вокруг планеты; тап (или пробел) срывает его с орбиты, и он летит по касательной. Поймай орбиту следующей планеты выше и поднимайся как можно дальше.

- **Звёзды** дают очки, быстрые перелёты (меньше 0,75 с) повышают комбо до x5.
- **Бонусы:** щит (спасает от одного астероида), магнит (притягивает звёзды), замедление.
- **Проигрыш:** слишком долгий полёт, вылет за край экрана или столкновение с астероидом.
- 6 скинов спутника открываются по рекорду. Рекорд хранится в браузере.

Управление: тап / клик / пробел / Enter / ↑ запускают спутник, Esc / P ставят паузу. Работает на телефонах (портрет и ландшафт), планшетах и ПК.

## Запуск

Без сборки и зависимостей: откройте `index.html` или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
```

## Структура

- `SPEC.md` — контракт модулей (по нему 30 агентов писали каждый свой файл).
- `js/*.js` — модули игры в пространстве имён `window.ORB`, `js/game.js` — главный цикл.
- `css/style.css` — адаптивный интерфейс.
- `tools/check.js` — headless-проверка API и игровой логики: `node tools/check.js`.
- `tools/build.js` — сборка в один файл `dist/orbita.html`: `node tools/build.js`.
